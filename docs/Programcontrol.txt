Programcontrol
--------------
- filehandler : Filehandler
-----------------------------
+ Programcontrol()
+ listFiles() : String
+ handleRequest(request : String) : String


Purpose of the class:
This program control class will be constructed to retrieve the file contents from
file handler class, determine between no argument inputs and argument inputs and
connect contents back into command line interface

It has functions that execute the:
Retrieval of file contents
The spewing back of information into user interface command line
The returning of readable text

Pseudocode:

files <- filehandler.listFiles()

index <- convert request to integer
index <- index - 1

IF index is invalid
    RETURN "Invalid file number."

fileName files[index]

content  filehandler.readFile(fileName)

RETURN content
