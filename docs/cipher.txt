Purpose of this class
The Cipher class handles the decryption of text using a substitution cipher.
It reads a key file (defaulting to ciphers/key.txt) to build a mapping of ciphered characters to original characters.
It validates the key file format and provides a decipher method to decode strings.

Pseudocode:

Cipher(keyFilePath)
    Validate keyFilePath is not null/empty
    Load key file from path
    Validate file exists, is readable, and has valid format (2 lines, unique chars)
    Build cipherToPlain map
    Set keyValid = true

decipher(cipheredText)
    If cipheredText is null, return null
    If cipheredText is empty, return ""
    Create StringBuilder
    For each char in cipheredText:
        If char is in cipherToPlain map:
            append mapped original char
        Else:
            append char unchanged
    Return built string

Error handling:
try { new Cipher() }
catch (CipherException e) { e.getMessage() }

CipherException provides ErrorType enum for specific handling (KEY_FILE_NOT_FOUND, etc).
