Purpose of this class
The Userinterface class is meant to provide the interface in which the user interacts with (terminal).
This involves handling the argument when the user runs java TopSecret [argument]


startProgram(String[] args)
The startProgram method validates the argument (should only contain numbers and be
one argument). If the argument is valid (empty or only digits) then startProgram creates and calls
the Program control class and argument handler. Otherwise, an exception occurs and rhe user is notified
of the error.


Pseodocode:

startProgram(String[] args)
    Programcontrol pc = new Programcontrol()
    if args.length == 0:
        pc.listFiles
    else if args.length == 1
        pc.getfile(args)
    else:
        error

Tests:
Only valid inputs are those with one argument and contains digits.
Test every other combination of argument; eg multiple arguments, including letters,
etc -> all of these should result in an error or exception
